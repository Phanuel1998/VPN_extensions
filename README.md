# 🌐 Isolated Browser VPN Extension

یک افزونه (Extension) قدرتمند برای مرورگرها که به شما اجازه می‌دهد ترافیک وب‌گردی خود را از طریق یک سرور اختصاصی هدایت کنید، **بدون اینکه نیازی به تغییر پروکسی یا VPN کل سیستم‌عامل (ویندوز) داشته باشید.**

این پروژه با هدف استقلال شبکه مرورگر از شبکه اصلی ویندوز طراحی شده است.

## ✨ ویژگی‌های کلیدی

*   **استقلال کامل شبکه:** ترافیک مرورگر از سیستم‌عامل کاملاً جدا می‌شود (ایده‌آل برای دولوپرها).
*   **معماری ساختاریافته:** شامل بیش از ۲۰۰۰ خط کد بهینه برای مدیریت بدون نقص درخواست‌های شبکه.
*   **رابط کاربری مینیمال:** اتصال و مدیریت سرور تنها با چند کلیک ساده.
*   **توسعه سریع (AI-Powered):** این پروژه به عنوان یک نمونه موفق از برنامه‌نویسی به کمک هوش مصنوعی (AI Studio) در کمتر از ۳۰ دقیقه توسعه داده شده است.
